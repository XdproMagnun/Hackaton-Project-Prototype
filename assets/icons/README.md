# Iconos de la aplicación

Copias de los SVG originales de ASSETS_ICONS, con nombres estables para web. Los archivos de metadatos ._* no son imágenes y no se distribuyen.

- account: perfil local editable; sin autenticación ni sincronización.
- chevron-down/up/left/right: expandir, contraer y desplazarse.
- help: ayuda de uso y explicación de camiones simulados.
- bell / bell-off: activar o silenciar avisos opcionales dentro de la app; sin notificaciones push ni GPS.
- check / close: confirmar y cancelar o cerrar.
- home: regresar al mapa general.
- map: mapa y recorridos.
- more: opciones secundarias en el menú compacto.
- place: ubicación o destino.
- stop: paradas; se conserva el número del marcador.
- bus: posiciones de camiones.
- logo-app: favicon; logo-full: identidad completa en la cabecera.

icons.css usa máscaras SVG para heredar el color del botón. icons.js crea iconos decorativos ocultos a lectores de pantalla; cada control mantiene su texto o nombre accesible.

Paleta: fucsia #F20675, violeta #9747FF y amarillo #F2B705. theme.css utiliza variantes oscuras para texto legible sobre blanco. Corazón: favoritos locales; ojo: visibilidad de capas; loading: carga; warning: precisión del recorrido. Los carteles se presentan como miniaturas en Referencias. Las capturas de pruebas de la raíz no se usan como imágenes de producto.
